# COVID-19 Data Analysis

This project contains analysis and visualization of COVID-19 data using Python's pandas and matplotlib libraries.

## Dataset Source
The dataset used in this analysis is sourced from Our World in Data, accessible at: [owid-covid-data.csv](https://covid.ourworldindata.org/data/owid-covid-data.csv)

## How to Run the Analysis
1. Fetch the latest data:
   ```bash
   python fetch_data.py
   ```
2. Run the main analysis:
   ```bash
   python main.py
   ```
3. View the plots in the `plots` directory.
